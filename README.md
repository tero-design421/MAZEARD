MAZEARD: Wilds Reclaimed

An Indie Fantasy-Futuristic Tactical RPG

About the Game

MAZEARD is an adventure RPG set in a mysterious world where ancient magic, wild nature, and advanced technology coexist.

Players explore villages, recruit unique characters, discover their stories, and build teams to face tactical turn-based battles and dangerous expeditions.

Core Features

- Character Recruitment: Explore villages, meet NPCs, and recruit unique characters.
- Unique Abilities: Every character has special skills, roles, and tactical abilities.
- Strategic Combat: Turn-based tactical battles with different character classes and abilities.
- Exploration: Discover mysterious environments, hidden secrets, and ancient ruins.
- Expeditions: Explore challenging mazes filled with encounters and discoveries.
- A Living World: A blend of fantasy, nature, magic, and futuristic technology.

Visual Identity

The game features multiple visual environments, ranging from natural fantasy forests to futuristic cyberpunk regions, with hybrid worlds combining both styles.
